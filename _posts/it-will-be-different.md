Hi everyone! I thought I'd share what I've been working on and will be working on for a while.

The first thing I'd like to start with is the Luna SSG engine. It will get its own GitHub account, so it won't be a subfolder on my personal account. I'll also be rethinking the content organization (it's pretty flat right now). At the same time, the engine will outgrow itself, and the blogging engine will become an engine for any website. The engine will still generate a static site, which brings me to another piece of news.

From now on, my personal website will no longer use this engine. The thing is, as a fairly creative person, I find myself missing the freedom of a static website. Working on audio support in the format I wanted clearly demonstrated this. Therefore, my personal website will continue to develop on its own for a while.

The second thing is the music, which I've been working on all this time. I already have about seven compositions, and I think that's quite a lot. They're all in different genres (almost), ranging from synth-pop to solo piano. I'd also like to point out that they're all imbued with the spirit of Annoying Dog (if you know, you know), and I even think I nailed it, which is why I called this attempt "A Dog's MIDI Collection." I'll post it later, once I've finished adding audio player support (I'm pretty lazy about this).

That's probably all for now. There will be some more changes, and I'll definitely write about them (if it's worth it).
